# 前端视觉重设计 —— 现代商务精炼（仅样式，不改功能）

## 一、背景与目标（Context）

`frontend/` 是一个 Vue 3 + Ant Design Vue 4 + ECharts 的 HR 管理前端。现状问题：`style.css` 的设计令牌层级扁平（`--text-primary` 与 `--text-secondary` 都是 `#000000`，标题/正文/次要文字无法区分）、边框与阴影只有单层、卡片表面缺乏层次；排版缺少比例体系，数字缺乏等宽对齐。

本次目标：**用「现代商务精炼」方向做全站视觉重设计**——保留「深色侧栏 + 浅色内容区」的整体结构，重点提升排版层级、间距节奏、卡片/表面细节、边框阴影，并统一为单一低饱和蓝强调色。**严格不改变任何行为**：不动 API 调用、路由、状态管理、事件处理、DOM 中承载行为的 ref/类名/滚动容器与 ECharts 容器引用。

关键杠杆：多数 CRUD 页面（employee / jobPost / resume / performance / trainingCourse / abilityTag / resumeAbilityRel / flow）**没有 scoped 样式**，完全依赖全局类 + AntD 组件 → 只需改设计令牌与 AntD 主题即可整体升级，无需逐页改。重度自定义页面（dashboard / agent / login / selfService / contractReview / architecture / todo）需单独重设计。

## 二、设计方向与原则

- **方向**：现代商务精炼。克制的层次、精确的间距、细腻的表面与描边，单色强调。
- **不做**：卡通元素、emoji、花哨装饰、多色渐变堆砌；不引入与业务无关的插画。
- **字体策略**：**纯系统字体栈，不加载 CDN 网络字体**。理由：应用面向内网/离线环境；CJK 网络字体体积达数 MB，会造成 FOUT 与首屏阻塞，可靠性差。Latin/数字置于栈首以优先命中更好的字形，中文回退到系统字体。

```css
--font-sans: "Inter","Segoe UI Variable Text","Segoe UI",-apple-system,BlinkMacSystemFont,
             "PingFang SC","Microsoft YaHei","Noto Sans SC","Hiragino Sans GB",Roboto,Arial,sans-serif;
--font-num:  "JetBrains Mono","Cascadia Mono","SF Mono",Consolas,"Microsoft YaHei",monospace;
```

## 四、不可破坏的行为约束（风险清单）

1. **滚动/高度**：`.app-root{height:100vh;overflow:hidden}`、`.menu-wrap`、`.app-content`、`.chat-messages`、`.chat-page{height:100%}` 的高度与 overflow 不得改动，否则折叠侧栏、内容滚动、聊天自动滚动（`scrollToBottom()` 读 `scrollTop/scrollHeight`）会失效。
2. **ECharts**：不得改图表容器 ref、高度与父级 `display/overflow`，否则 `resize` 时容器塌陷为 0。
3. **`:deep()` 与作用域**：BasicLayout 覆盖 AntD Menu 的选择器结构保留，只改值；不把 scoped 规则搬到全局，避免与 JS 切换类名的作用域错配。
4. **组件令牌 vs 全局 CSS 冲突**：同一属性只选一处来源（优先 AntD 主题令牌，全局仅保留表格 hover 覆盖）。
5. **Markdown**：不重命名 `marked` 渲染 HTML 对应的 `.markdown-body :deep(...)` 选择器，只调值。
6. **行为耦合标记**：`v-model:collapsed`、`v-if="!collapsed"`、`v-if="showWelcome"`、`msg.thinkingExpanded` 等类名/条件保持不变。
