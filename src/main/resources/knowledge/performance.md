# 绩效考核管理制度

> 分类: 绩效管理 | 可见性: PUBLIC | 关键词: 绩效,考核,KPI,OKR,评级,强制分布,绩效面谈

公司实行季度考核与年度考核相结合的绩效管理制度。季度考核侧重目标达成与过程管理，年度考核综合四个季度结果与能力表现，作为调薪、晋升与奖金分配的主要依据。

考核采用 OKR 与 KPI 相结合的方式：业务岗位以量化 KPI 为主，研发与职能岗位以 OKR 关键结果达成度为主。每季度初由员工与直属主管共同确定本季度目标并录入系统，目标数量原则上不超过 5 项。

考核维度与权重：业绩结果占 60%，能力表现占 25%，价值观与协作占 15%。评分采用 1 至 5 分制，其中 5 分需有突出贡献支撑，4.5 分及以上占比不超过团队 20%。

绩效等级分为 S（卓越）、A（优秀）、B（合格）、C（待改进）、D（不合格）五档。考核结果遵循强制分布：S 不超过 10%，A 与 S 合计不超过 30%，C 与 D 合计不低于 5%。连续两个季度考核为 C 的员工，进入绩效改进计划（PIP），改进期 3 个月；改进期结束仍未达标的，公司可调整岗位或依法解除劳动合同。

绩效面谈：直属主管须在考核结果确认后 5 个工作日内与员工完成一对一绩效面谈，反馈亮点与改进建议，双方确认签字。员工对考核结果有异议的，可在结果公布后 3 个工作日内向人力资源部提出申诉，人力资源部会同上级主管在 5 个工作日内复核并答复。

绩效结果的应用：S 级员工优先纳入晋升与关键人才盘点，年度奖金系数 1.5 至 2.0；A 级系数 1.2 至 1.5；B 级系数 1.0；C 级系数 0.6 至 0.8 且不具备当期调薪资格；D 级不参与奖金分配并不具备晋升资格。
