# HR智能助手Agent系统 30天开发执行计划
> 文档版本：V1.2  
> 编制部门：技术部  
> 适用对象：后端开发组 + 前端开发组  
> 执行周期：30个工作日  
> 核心目标：基于 **LangChain4j + LangGraph4j** 技术栈完成HR智能Agent MVP版本全量开发，覆盖**简历初筛与人岗匹配、员工入离调转流程自动化、绩效数据自动汇总、个性化培训计划生成、模拟求职者公开投递**五大核心场景，通过集成测试与安全校验，具备企业内部演示与试用条件。

---

## 一、项目整体说明
### 1.1 业务范围界定
本次开发为MVP版本，聚焦HR部门高频刚需场景 + 前端模拟投递演示入口，核心交付能力：
1.  简历智能解析与结构化提取，支持PDF/Word/图片格式简历
2.  人岗智能匹配，支持硬规则筛选+语义相似度综合评分，自动生成初筛意见
3.  员工入、离、转、调全流程线上自动化，对接审批流与自动办理节点
4.  绩效数据多源自动汇总、核算与结果生成，支持定时执行
5.  基于员工能力画像与岗位要求，个性化生成培训计划
6.  统一Agent对话入口，支持自然语言查询HR数据、发起流程、获取指引
7.  公开模拟求职者投递页面，支持岗位选择、简历上传提交，全链路自动触发解析与匹配

### 1.2 既定技术栈（全员统一执行）
| 技术分层 | 选型组件 | 备注 |
| :--- | :--- | :--- |
| 基础框架 | Spring Boot 3.2.x + Maven多模块 | 遵循公司Java开发规范 |
| 持久层 | MySQL 8.0 + MyBatis-Plus 3.5.x + 代码生成器 | 复用现有组件封装 |
| 缓存与锁 | Redis 7.x + Redisson | 分布式锁、热点数据缓存、会话状态存储 |
| 检索与向量 | Elasticsearch 8.12.x | 兼顾关键词检索与向量语义匹配，对接LangChain4j存储规范 |
| 消息队列 | RabbitMQ 3.12.x | 异步解耦、削峰填谷 |
| 流程引擎 | Flowable 7.0.x | 入离调转审批流驱动 |
| 定时任务 | XXL-Job 2.4.x | 分布式定时任务调度 |
| **AI核心框架** | **LangChain4j 0.32.x + LangGraph4j** | Java生态主流LLM开发框架；内置RAG、工具调用、记忆管理；LangGraph实现有状态Agent编排，支持复杂业务分支与循环 |
| 大模型服务 | 阿里云通义千问(DashScope) | 对接LangChain4j原生模型适配器，支持Embedding、Chat、Function Calling |
| 文件存储 | MinIO | 简历、培训课件等文件私有化存储 |
| 文档解析 | Apache POI + Apache PDFBox + 阿里云OCR | 覆盖文本型与扫描件简历 |
| 前端技术 | Vue3 + Element Plus | 管理后台 + 模拟求职者投递页 |
| 安全权限 | Spring Security + JWT + 数据脱敏 | 内部接口鉴权；公开投递接口免登录，做限流防护 |

## 三、30天每日详细开发排期

### 第一阶段：需求与架构设计（第1-5天）
#### 第1天：项目启动与需求终评
- 核心任务：
  1.  召开项目启动会，明确项目目标、排期、分工与协作规则
  2.  联合HR业务方，对四大模块的业务规则、流程节点、异常场景进行最终评审
  3.  确认模拟求职者投递端的功能边界、数据隔离规则与安全要求
  4.  确认各模块边界与优先级，明确MVP版本裁剪范围
- 交付物：《HR智能Agent需求规格说明书V1.2》
- 验收标准：业务方与开发组共同签字确认，需求无歧义

#### 第2天：系统架构设计与技术方案评审
- 核心任务：
  1.  输出系统分层架构图、模块依赖图、数据流向图
  2.  设计Agent智能层架构：LangChain4j负责基础能力链（RAG、单一场景生成），LangGraph负责多工具、多步骤的有状态Agent编排
  3.  设计公开投递端与内部系统的隔离架构，明确接口权限与数据边界
  4.  评审大模型调用方案、向量检索方案、流程引擎与Agent联动方案
- 交付物：《系统架构设计文档》《LangChain+LangGraph技术落地方案》
- 验收标准：架构方案通过技术委员会评审，无技术风险点

#### 第3天：数据库模型设计
- 核心任务：
  1.  设计全部核心业务表：简历表、岗位表、员工表、流程实例表、绩效表、培训课程表、能力标签表等
  2.  新增Agent会话表、对话历史表、工具调用日志表，适配LangGraph状态持久化需求
  3.  简历表新增「投递来源」字段，区分HR后台上传与求职者投递
  4.  设计索引、分表策略、敏感字段加密规则，输出建表SQL与ER图
- 交付物：数据库设计文档、建表SQL脚本、ER图
- 验收标准：覆盖全部业务场景，字段设计无遗漏，符合数据库设计规范

#### 第4天：开发环境与中间件部署
- 核心任务：
  1.  统一开发环境版本，完成MySQL、Redis、Elasticsearch、RabbitMQ、MinIO、XXL-Job的部署与连通性验证
  2.  申请通义千问API密钥、OCR接口权限，完成LangChain4j通义千问适配器的连通性测试
  3.  配置Git仓库，划分开发分支、测试分支、生产分支
  4.  前端开发环境初始化，搭建Vue3项目基础骨架
- 交付物：《开发环境部署手册》、中间件连通性验证报告
- 验收标准：所有中间件可正常连接，LLM接口调用成功

#### 第5天：项目骨架搭建与代码规范落地
- 核心任务：
  1.  创建Maven多模块工程，划分common、dao、service、controller、agent-core、agent-graph、flowable、open-api等模块
  2.  统一代码规范、注释规范、接口返回规范、异常处理规范
  3.  集成MyBatis-Plus代码生成器，生成基础实体类与Mapper
  4.  前端项目完成路由配置、Element Plus引入、基础样式统一
- 交付物：可运行的基础项目骨架、《代码开发规范》

## 四、模拟求职者投递端 核心实现参考
### 4.1 前端页面核心代码（Vue3 + Element Plus）
```vue
<template>
  <div class="resume-deliver-container">
    <el-card class="deliver-card">
      <template #header>
        <div class="card-header">
          <span>简历投递（模拟求职者端）</span>
        </div>
      </template>

      <el-form :model="form" label-width="80px" ref="formRef">
        <el-form-item label="应聘岗位" prop="jobId">
          <el-select
            v-model="form.jobId"
            placeholder="请选择应聘岗位"
            style="width: 100%"
          >
            <el-option
              v-for="item in jobList"
              :key="item.id"
              :label="item.jobName"
              :value="item.id"
            />
          </el-select>
        </el-form-item>

        <el-form-item label="简历文件" prop="file">
          <el-upload
            ref="uploadRef"
            :auto-upload="false"
            :limit="1"
            accept=".pdf,.doc,.docx,.jpg,.png"
            :on-change="handleFileChange"
            :on-exceed="handleExceed"
            drag
          >
            <el-icon class="el-icon--upload"><upload-filled /></el-icon>
            <div class="el-upload__text">
              将简历拖到此处，或<em>点击上传</em>
            </div>
            <template #tip>
              <div class="el-upload__tip">
                支持 PDF / Word / 图片格式，单个文件不超过 10MB
              </div>
            </template>
          </el-upload>
        </el-form-item>

        <el-form-item>
          <el-button
            type="primary"
            style="width: 100%"
            :loading="submitting"
            @click="submitDeliver"
          >
            提交投递
          </el-button>
        </el-form-item>
      </el-form>
    </el-card>
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import { ElMessage } from 'element-plus'
import { UploadFilled } from '@element-plus/icons-vue'
import axios from 'axios'

const formRef = ref()
const uploadRef = ref()
const submitting = ref(false)
const jobList = ref([])
const form = ref({
  jobId: '',
  file: null
})

onMounted(() => {
  getOpenJobList()
})

// 获取公开岗位列表
const getOpenJobList = async () => {
  try {
    const res = await axios.get('/api/open/job/list')
    jobList.value = res.data || []
  } catch (e) {
    ElMessage.error('岗位列表加载失败，请稍后重试')
  }
}

// 文件选中回调
const handleFileChange = (file) => {
  form.value.file = file.raw
}

// 文件超出数量限制
const handleExceed = () => {
  ElMessage.warning('只能上传一份简历')
}

// 提交投递
const submitDeliver = async () => {
  if (!form.value.jobId) {
    ElMessage.warning('请选择应聘岗位')
    return
  }
  if (!form.value.file) {
    ElMessage.warning('请上传简历文件')
    return
  }

  submitting.value = true
  const formData = new FormData()
  formData.append('jobId', form.value.jobId)
  formData.append('file', form.value.file)

  try {
    await axios.post('/api/open/resume/deliver', formData, {
      headers: { 'Content-Type': 'multipart/form-data' }
    })
    ElMessage.success('投递成功！我们会尽快处理您的简历')
    uploadRef.value.clearFiles()
    form.value.jobId = ''
  } catch (e) {
    ElMessage.error(e.response?.data?.message || '投递失败，请稍后重试')
  } finally {
    submitting.value = false
  }
}
</script>
