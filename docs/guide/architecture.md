## 核心模块说明

### AI Agent 引擎

基于 LangChain4j + LangGraph4j 构建的状态机驱动的 AI Agent 系统：

| 节点 | 职责 |
|------|------|
| **意图识别** | 分析用户输入，提取意图和参数 |
| **工具调用** | 匹配并调用对应的业务工具 |
| **思考推理** | 处理工具返回结果，生成最终回答 |

工具链采用**动态加载**策略，根据用户意图只加载相关工具，减少 Token 消耗。

### 工作流引擎

基于 Flowable BPMN 2.0，支持：

- 入职审批流程
- 离职审批流程
- 调岗审批流程
- 转正审批流程

### 数据看板

提供系统级数据统计与可视化，包括：

- AI 交互统计（对话量、Token 消耗、工具调用）
- 业务概览（员工、简历、流程、绩效）
- 每日趋势分析
- 最近活动日志

## 安全设计

- 敏感字段（手机号、身份证、工资）AES-256-CBC 加密存储
- 防重复提交（Redis SETNX + 3 秒 TTL）
- 接口限流（2 次 / 5 秒）
- 分布式锁（Redisson RLock）
