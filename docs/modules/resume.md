# 简历管理

## 功能说明

简历管理模块支持简历的录入、筛选、面试、录用全流程管理，跟踪候选人状态流转。

## 数据模型

| 字段 | 类型 | 说明 |
|------|------|------|
| candidate_name | varchar(50) | 候选人姓名 |
| phone | varchar(255) | 手机号（加密存储） |
| email | varchar(100) | 邮箱 |
| target_job_id | bigint | 目标岗位 ID |
| owner_emp_id | bigint | 负责 HR 员工 ID |
| resume_status | tinyint | 简历状态：0-待筛选，1-面试中，2-录用，3-归档 |
| source | varchar(50) | 简历来源 |

## 简历状态流转

```
待筛选 → 面试中 → 录用 → 归档
  ↑        ↑
  └────────┘ (可回退)
```

## AI 助手操作

- **查询**："查询最新的简历"
- **筛选**："筛选技术岗位的简历"
- **录入**："新增一份简历，候选人叫张三，应聘Java开发"
- **录用**："将李四的简历状态改为录用"
- **分析**："分析这份简历的能力匹配度"

## 相关接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/resume/list` | GET | 简历列表查询 |
| `/resume/get/{id}` | GET | 简历详情 |
| `/resume/save` | POST | 新增简历 |
| `/resume/update` | PUT | 更新简历 |
| `/resume/delete` | DELETE | 删除简历 |
